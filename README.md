# 🥭 MANGO JUMP 芒果醬活動資訊站

## 網站功能

### 🗓️ 近期活動
- 列出即將到來的演出，包含日期、時間、地點與備註。
- 可切換「條列」或「月曆」檢視，月曆上會標示演出日。
- 提供導航地圖連結，方便規劃出門路線。

### 📋 詳細場次
- 收錄歷年演出紀錄，點選場次即可展開當天的歌單。
- 可依年度篩選，也能查看歷年總計。
- 登入後可勾選自己參加過的場次，留下專屬的現場足跡。

### 📊 歌單分析
- 統計每首歌在場次中的出現率，可依近 4 場、8 場、12 場或自訂場數查看。
- 提供總榜與近期榜並列比較，並以標籤標示近期的變化：
  - 🔥 **發燒中**：近期出現率明顯高於整體平均。
  - ❄️ **冬眠中**：熱門曲目近期未曾演唱。
  - 💎 **中樂透啦**：稀有歌曲近期意外登場。
- 輸入歌名即可快速查詢出現率，也能查看每首歌的累積出現曲線。

### 🎲 隨機聆聽
- 隨機抽選一首歌，適合想聽點不一樣的時候。
- 可直接觀看 MV 或前往各大音樂平台收聽（Spotify、KKBOX、Apple Music、YouTube Music）。
- 顯示歌詞，方便跟唱。
- 支援「連續隨機」，播完自動換下一首。
- 可分享抽到的歌曲連結給朋友。

### 👤 我去哪芒（個人足跡）
- 以專屬 ID 建立個人頁面，不需註冊帳號即可使用。
- 記錄參加過的場次，並依參加次數解鎖成就稱號，從「初階果汁機」一路升級到「傳奇芒果教父」。
- 查看「尚未相遇的歌」與金曲收藏庫，知道還有哪些歌等待在現場聽到。
- 可設定個人暱稱。

### 📝 場次補充回報
- 歡迎粉絲協助補全演出資訊與歌單。
- 填寫日期、活動名稱、表演時間與歌曲順序（可標記安可）後送出，等待審核後更新。

### 🎨 其他特色
- 三種主題風格：日間、夜間與芒果色，依喜好切換。
- 手機、平板與電腦皆可瀏覽。
- 頂部公告列，重要消息第一時間通知。

---

## 如何使用

1. 開啟 [網站連結](https://blues32767.github.io/mangojump-setlists/)。
2. 從首頁查看近期活動，或從上方選單進入其他頁面。
3. 想看歌單就到「詳細場次」，想找歌就到「歌單分析」，想隨機聽歌就到「隨機聆聽」。
4. 若想留下自己的足跡，請到「我去哪芒」建立或輸入專屬 ID。
